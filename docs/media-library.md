# 媒体库使用教程

面向使用者的一页教程。左侧导航的「媒体库」这一页能干什么、要什么前提、参数在哪调、点了没反应怎么办。

一句话：**把你已有的 Jellyfin / Emby / Plex / 飞牛影视 媒体库当成一个可搜索的片库来浏览**。
它是只读的 —— 不播放、不下载、不改动媒体库；每张卡片上的「访问」是跳回那台服务器自己的页面。

---

## 1. 前提：先有一台已启用的媒体服务器

这一页自己不存任何东西，它读的是左侧「媒体服务器」页里配置的服务器。没有已启用的服务器，这页什么都做不了
（表现见 §5 第一条）。

去「媒体服务器」页点「添加媒体服务器」，五项：

| 字段 | 说明 |
|---|---|
| 服务器类型 | Jellyfin / Emby / Plex / 飞牛影视（FNOS）四种，选完下面的认证字段会跟着变 |
| 名称 | 你自己看的名字，会显示在卡片右下角和错误提示里 |
| 地址 | 形如 `http://192.168.1.10:8096/`。**必须是运行浏览器的这台机器能直接访问到的地址**（内网/VPN 都行，扩展不会替你翻墙） |
| 请求超时（秒） | 一次请求等多久，默认 **5 秒**（存的是毫秒）。库大、机器慢可以放到 10~30 |
| 启用 | 关掉就不会参与搜索（注意：范围列表里也选不到它） |

各类型要的认证信息：

| 类型 | 认证字段 | 拿法 |
|---|---|---|
| Jellyfin | `apikey`（必填）、`userId`（可选） | apikey 可在 Jellyfin 控制台面板执行 `var c = JSON.parse(localStorage.getItem("jellyfin_credentials")).Servers[0]; console.log({AccessToken: c.AccessToken, UserId: c.UserId});` 拿到；也可以在服务端的「API 密钥」里新建一把。`userId` 只有你想要「已观看 / 已喜欢」角标时才需要填 |
| Emby | `apikey`（必填）、`userId`（可选） | 同上，Emby 的 API 密钥在服务端「高级 → 安全密钥」里生成 |
| Plex | `apikey`（必填） | 就是 X-Plex-Token：在 Plex Web 任意一个带 `X-Plex-Token=` 参数的请求里复制 |
| 飞牛影视 | `username`、`password`（必填）、`parentId`（可选） | 用你的登录账号密码，扩展会调 FNOS 的登录接口自动换 token。`parentId` 不填时扩展自己读取媒体库视图再在视图下搜索 |

> 凭据只存在扩展自己的本地存储里（chrome.storage，跟这台浏览器的扩展 profile 走），不会同步到任何第三方。

## 2. 搜索框：留空是「浏览」，填词是「搜索」

- **留空 + 搜索**：浏览整库，但**顺序由服务器定**，各家不一样：
  - Jellyfin / Emby：随机顺序（填了 `userId` 时是「收藏/喜欢优先 + 随机」），所以每次进来看到的批不一样；
  - Plex：走的是「最近更新」列表（`/library/recentlyAdded`），不是随机；
  - 飞牛影视：按媒体库视图取（不填 `parentId` 时自动读你所有视图）。
- **输入关键词 + 搜索**：按片名搜，关键词原样发给每台服务器，匹配习惯沿用各家。
  - Emby 额外支持一种高级写法：`imdb|tt1234567` 会转成按 IMDb 号精确查（其它类型没这个语法）。
- **类型过滤各家不一样**：Jellyfin / Emby 无论浏览还是搜索，都固定只取**电影和剧集**（`Movie,Series`）；
  飞牛影视只在**搜索时**加这个过滤，留空浏览时不限类型；Plex 不带类型过滤，接口返回什么就显示什么。
- 冷启动进这一页默认就会自动浏览一次（可在「常规设置」里关掉，见 §4）。

搜索框**左边那个数据库图标**是「哪些服务器参与这次搜索」的选择面板：

- 默认 = 所有**已启用**的服务器；
- 取消勾选只会影响本次会话内的选择，不会改动「媒体服务器」页里的启用开关；
- **全部取消 = 没有任何目标可问**，这时搜索框和「加载更多」都会变成禁用状态。

## 3. 结果、详情与「加载更多」

结果是瀑布流卡片，每张卡上的东西都来自服务器返回的元数据：

| 位置 | 内容 | 来源 |
|---|---|---|
| 封面 | 海报图 | Jellyfin / Emby 是从服务器的 `/Items/{Id}/Images/Primary` 直接取（**不带凭据**），Plex 的封面会带上 token。所以取不到图通常是内网不通或服务端禁止匿名取图，**不影响列表信息** |
| 左上标签 | 容器格式（如 MKV / MP4）+ 视频流标题、文件大小 | `Container` / 第一条 Video 流的 `Title` |
| 右上图标 | 已观看 ✓、已喜欢 ♥ | 需要填 `userId`，否则这两项恒空 |
| 卡片下方 | 片名（点开原页）、服务器名 + 类型图标 | — |
| 悬停遮罩 | 「详情」「访问」两颗按钮 | 「详情」开弹窗（类型 / 时长 / 大小 / 媒体信息），「访问」新标签打开服务器上的原页面 |

**各家返回的字段不完全一样**，所以同一张卡在不同服务器上信息量不同：

- **Plex**：搜索/浏览接口不给流信息（MediaSources），也不给观看与喜欢状态 —— 所以 Plex 的卡片右上是空的、
  「详情」弹窗里没有「媒体信息」那一栏；单集结果的标题会显示成 `剧名 (集名)`。
- **Jellyfin / Emby / 飞牛**：流信息、时长、大小、观看与喜欢状态（要 `userId`）都有。

**「加载更多」的语义**：不是翻这一页的下一页，而是**让每台服务器各自往后多取一批**
（每台记住自己上次取到哪：`startIndex += 每次数量`），再和已有结果按条目 URL 去重后拼进来。
所以：

- 结果是越点越多的，没有「上一页」；
- 某台服务器取完了（这一批没有新条目），它的「可加载更多」就关掉；全部关掉时按钮整体变灰；
- 默认还会**滚到底自动加载**（见 §4 那个开关），手动按钮是给关掉自动加载时用的。

## 4. 参数在哪调

「常规设置」→「搜索」标签里，媒体库相关的是这四项（名字照界面原样抄）：

| 界面上的项 | 默认 | 作用 |
|---|---|---|
| 单次检索条数上限 | 50 | 每点一次「加载更多」，每台服务器取多少条 |
| 同时检索服务器数 | 5 | 同时问几台服务器（只有一台时没有影响） |
| 打开搜索结果时自动检索媒体库 | 开 | 冷启动就自动浏览/搜索一次，不用手动点 |
| 滚动时自动加载更多媒体结果 | 开 | 滚到结果底部自动再取一批；关掉就只能按「加载更多」 |

## 5. 常见问题

**点搜索 / 点加载更多没反应**
这一页要有一个「可搜索的目标」才会发请求。三种来路都会导致空转，界面现在会把搜索框和按钮直接禁用，
并在空态里写明原因：

1. 「媒体服务器」页里一条都没有；
2. 添加了但「启用?」是关的；
3. 在搜索框左侧的数据库面板里把勾全取消了。

**弹「媒体服务器 X [地址] 更新失败：请检查认证信息」**
apikey / 账号密码不对或已失效（Jellyfin 重新登录、换设备后旧 key 会失效）。重新取一把填进「媒体服务器」页。

**弹的是别的原因（超时、无法访问、解析异常）**
提示里会直接写真实原因，不再是笼统的「检查认证信息」。超时就去调大那台的「超时」值；
无法访问先确认这台机器上用浏览器打开那个地址能不能通。

**卡片没有封面图**
Jellyfin / Emby 的封面是直接打那台服务器的图片接口、不带凭据的：内网不通、地址写错、或服务端禁止匿名取图都会没封面，
但片名、大小、详情这些照常。Plex 的封面带 token，取不到一般是地址或 token 本身的问题。

**右上没有「已观看 / 已喜欢」**
Jellyfin / Emby 需要填 `userId`；**Plex 永远不会有** —— 它的搜索接口不返回观看与喜欢状态。

**结果里少了某部片子**
先确认它在你勾选的那些服务器/视图里；飞牛影视没填 `parentId` 时是按自动读到的媒体库视图搜的，
视图之外的内容不会出现在结果里。

## 6. 这页现在**不做**什么（免得按宣传语去找功能）

- **不播放、不下载、不改动媒体库** —— 全程只读，「访问」只是新标签打开服务器自己的页面。
- 「媒体服务器」页顶部那句说明写的是「在搜索结果中联动检索媒体库、确认片库中是否已有对应影片」，
  但**这条联动目前没接**：站点搜索页和站点详情页上都没有跳到媒体库的入口，搜索结果里也不会标「片库里已有」。
  现在它就是一页独立的片库浏览器。
- 本页路由接受一个 `search` 查询参数用来预填关键词，那是给上面那条联动预留的，目前没有页面在用它。
